データは手元に。AIの仕組みは、みんなで育てる。

コモンズは、AI（Claude）に渡す仕事の進め方（スキル）だけを共有して、使うほど全員のAIが賢くなるようにする仕組みです。新しく入った人も、その共同体に合わせて調整されたAIを、初日から使えます。

「コモンズ」とは

もとは、村の入会地（いりあいち）や共同の牧草地のように、みんなで使い、みんなで手入れする資源と、そのための決まりごとを指す言葉です。経済学者のエリノア・オストロムは、使う人どうしが自分たちでルールを決めて守れば、共有の資源は荒れずに長く続くことを示し、2009年にノーベル経済学賞を受けました。

ここで共有するのは、土地ではなく AI の仕事の進め方（スキル）とルールです。使う人どうしで直し合い、育てていきます。

何を共有して、何を手元に残すか

共有する

AIへの作業の手順書（スキル）、守る基本ルール、表の設計図、公開された知識

手元に残す

人名・金額・取引先などの事業のデータ。各自の Notion・会計ソフト・Google Drive に置いたまま

全体の形

土台のコモンズ（ground）どのコモンズも使う、業種を問わないスキルと基本ルール
↓ スキルを取り込む　　↑ 分かったことを返す
家庭のコモンズ暮らしのこと
ワイン生産者のコモンズ畑・栽培、知識コモンズ
ぶどう園の会社のコモンズその会社のやり方

個別のコモンズは、土台のスキルを取り込み、自分たちの事情に合わせて足して使います。分かったことを返すと、次に届く土台が良くなります。土台は個別のコモンズの中身に口を出さず、いつでも一部を外せます。

はじめかた

あなたがやること
  1. Claude を Pro 以上にする （1分）
  2. Claude に Notion をつなぐ （3分）
  3. プラグインの画面で、マーケットプレイス commons-ground/ground を足して、使うプラグインを入れる （5分）
  4. 個別のコモンズに入る人は、招待リンクで Discord に入り、#一般 のピン留めにある入口を Claude のコネクタに足して「Discord でログイン」 （5分）
  5. 使ってみて、気づいたことはそのまま Claude に言う

画面ごとの手順を見る

あとは自動で
  • 誰かがスキルを直すと、次の日から自分の Claude にも届く
  • 入れたスキルは、どのチャットでも効く
  • ほかの人にも効く気づきは、Claude が名前や金額を抜いて、土台への提案にまとめる
  • 自分の Claude から Discord を読み書きできる。作ったものは「Discord に共有して」で仲間に届く
  • 打ち合わせの記録を渡せば、出たアイデアを Claude が試しに仕組みへ入れる

Claude を契約していない人は、手順は要りません。家庭や会社のコモンズに AI がいれば、Notion のコメントで「@AIの名前」と書くだけで使えます。

自分たちに合わせる

軽い順に4段。上で足りるなら、下には降りません。

1. 選ぶ

使うスキルを選び、要らないものを外す

2. 値を入れる

どの表を使うか、部門の名前など

3. 上乗せ

土台のスキルに自分の分を足す。土台が直れば、その改善も届く

4. 自分のスキル

土台に無いものを作る

守ること

  • 事業のデータを、土台に入れない
  • 同じスキルを2か所に置かない。コピーせず、上乗せで合わせる
