# 考えて話す型の練習づくり

返答・成果物はすべて日本語。人向けの言葉はシンプルに。比喩的な言い回しは避ける。

## いちばん大事なこと

ワークショップの中心の問いには、その場に固有の「考えて話す型」がある。たとえば「選んだ当たり前を、なぜ大切だと感じるか」なら、**具体的な形（バスの便数）から、一段上の理由（自分で好きなときに出かけられる）へ上がり、それを自分の暮らしの場面で話す**のが型になる。

参加者は放っておくと、ふだん話しやすい型（手癖）で話す。手癖は本人も気づかない型で、場の決まりが弱いほどそちらに流れる。温度の高い、話好きの場ほど一気に流れる。

だから、**アイスブレイクとグランドルールは、空気を和ませるためだけでなく、本番の型を前もって体で覚えてもらうためにある**と考える。ブレストのルールを守ってもらうのと同じで、その場の型にある程度合わせてもらうことは、参加者に失礼ではなく、場の役目。

世の中のアイスブレイクの多くは、良いチーム一般の型（名前で呼び合う、否定しない、前提を疑う）を覚えるためのもの。そのまま使っても、その場固有の型は身につかない。**本番と同じ型を、軽い題材で一度やる**ように作り変える。

## 手順

🧭 AI設定ページの自分ルール（このスキルの欄）があれば先に読む。手持ちのアイスブレイク集の置き場（論理名 `icebreak_library`）が書いてあれば、手順4で使う。

### 0. 受け取る

分からないものだけ、まとめて1回聞く。

- 本番の中心の問い（問いの言葉そのもの）
- 答えを誰が何に使うか（例：市が計画の「めざす姿」を書く材料にする）
- 参加者（人数、年代、慣れ、温度）と、場にいる立場の違う人（行政の職員、専門家、主催者）
- 本番までの流れと時間、使う道具（カード、シート、スライド）

### 1. 求める型を、答えの例で書く

型を抽象的に書かず、**実際の材料で答えの例を2列に並べる**。

| ふだんの型で出る答え | この場で欲しい答え |
|---|---|
| 「医療は人命に関わるから大事」（一般論） | 「先月、夜に子どもが熱を出したとき、車で10分の病院が開いていて助かった」（自分の場面） |
| 「バスの便を増やしてほしい」（形・要望） | 「バスがあると、運転しない母が自分で買い物に行ける」（形の一段上の理由） |

右の列から、型を**動き**で一文にする。例：「形 → それがあると何ができるか → それを感じた場面」。この一文が、以降の仕掛けすべての軸になる。

### 2. ずれを予想する

1の左の列がなぜ出るかを、構造から見る。人のせいにしない。よくある手癖と、それを生む構造：

| 手癖 | 生みやすい構造 |
|---|---|
| 形・施策の提案に流れる | 道具の文面がサービスの形で書いてある／事前情報に「ほかの例」がある／形を決める側（行政の職員）が近くにいる |
| 一般論・正論で答える | 「なぜ」と聞く／自分の場面を聞く追い問いがない |
| 要望・不満になる | 場の目的と範囲（この場で何を話し、何は別の場で扱うか）が示されていない |
| 前提に引っかかって入れない | 前提（例：人口が減る）への気持ちを受け止める場面がない |
| 問いを忘れて周辺の話になる | 説明から本番まで時間が空いて、直前の念押しがない |

### 3. 仕掛けを層で組む

1つの仕掛けに頼らない。次の層から、場に合うものを選んで重ねる。

| 層 | 何をするか | 気をつけること |
|---|---|---|
| アイスブレイク | 本番と**同じ型**を、**軽い題材**で一度やる（手順4） | ステップの数と答え方を本番とそろえる |
| グランドルール | 型をルールの言葉にする（例：「形の話が出たら『それがあると何ができる？』と聞き返す」） | 禁止より「こうする」で書く。4つまで |
| 必ず聞く追い問い | 話し手が話し終えたら、聞き手が決まった問いを**必ず**投げる。すでに答えていても投げる | 任意のヒントは使われないと考える。問いの言葉は question-design で作る |
| 直前の念押し | 本番の話し合いの直前に、型の見本（1の右の列の例）をもう一度見せる | 説明から時間が空くほど要る |
| 道具の欄 | シートの欄を型の順に並べる（形 → 何ができるか → 場面） | 書く欄がそのまま型になる |
| スタッフの声かけ | 巡回する人（行政の職員など）に、型に戻す一言を前もって渡す（例：「その形だと、何ができるからいいんですか？」） | 形を決める側の人は、形の質問に答えず、一段上を聞く役にする |
| 受け皿 | 型の外の話（形の提案、前提への違和感）を置く紙や欄を用意し、「これも届けます」と伝えてから戻す | 消さずに受け止めてから戻す |
| 範囲の示し方 | 冒頭で、全体の中でこの場が受け持つところと、受け持たないところを示す | 範囲が見えないと、範囲の外の話に流れる |

### 4. アイスブレイクを作る・選ぶ

手持ちの集（`icebreak_library`）や一般のアイスブレイクから探すときは、**題材ではなく型が同じか**で見る。作り変え方：

1. 本番の型の一文（手順1）を、そのまま手順にする（例：「身近な物を1つ挙げる → それがあると何ができる？ → それを感じた最近の場面は？」）
2. 題材を、答えに正解がなく、誰でも話せる軽いものにする（身近な物、昨日の出来事、好きな季節）。本番の題材（例：当たり前カード）は使わない。本番の答えを先取りしてしまうため
3. 本番と同じ人数・同じ役（話す、聞く、追い問いを投げる）でやる
4. 終わりに進行役が「今のと同じことを、このあとカードでやります」と型を言葉にしてつなぐ

一般のアイスブレイク（体を動かす、手あげ）は、型の練習とは別の役目（声と体を出す、正解がない空気を作る）として使ってよい。どちらの役目かを分けて置く。

### 5. 答えの例で試す

勧める前に、作ったアイスブレイクと追い問いを、参加者になったつもりで立場の違う3〜4人分演じて書く。question-design の「勧める前に、答えの例で試す」と同じやり方で、次を確かめる。

- アイスブレイクの答えが、手順1の右の列と同じ動きになっているか
- 1回やって型が見えるか（ステップが多すぎないか）
- 時間に収まるか（アイスブレイクは5〜10分が目安）

### 6. 出し方

最初に、求める型の一文（手順1）を書く。次に表で示す。

| いつ | 仕掛け | 何の型を体で覚えるか | 進行役の一言・台本 | 分 |
|---|---|---|---|---|

最後に、これがあっても外れたときの受け皿を一行書く。長さは question-design の「出し方」に合わせ、スマホの1〜2画面を目安にする。

## ほかのスキルとの分担

- 問いの言葉そのもの（中心の問い、追い問い）は **question-design** で作る。このスキルは、その問いに答える型を本番前に身につけてもらう仕掛けを作る
- 説明スライドの流れ（範囲の示し方、前提への気持ちの受け止め）は **slide-design** と合わせる
- 選んだ・捨てた案の記録は、question-design の「終わりに記録する」に従う

## ふりかえりで使うとき

場のあとに「理由まで深まらなかった」「要望ばかりだった」などが出たら、手順1と2を逆向きに使う。出た答えを左の列に並べ、どの構造が生んだかを見てから、次の回の仕掛けを手順3から組み直す。
