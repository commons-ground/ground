# 考えて話す型の練習づくり

返答・成果物はすべて日本語。人向けの言葉はシンプルに。比喩的な言い回しは避ける。

## いちばん大事なこと

ワークショップの中心の問いには、その場に固有の「考えて話す型」がある。たとえば「選んだ当たり前を、なぜ大切だと感じるか」なら、**具体的な形（バスの便数）から、一段上の理由（自分で好きなときに出かけられる）へ上がり、それを自分の暮らしの場面で話す**のが型になる。

参加者は放っておくと、ふだん話しやすい型（手癖）で話す。手癖は本人も気づかない。場の支えが弱いほど、そして話好きで温度の高い場ほど、そちらに流れる。

だからアイスブレイクやグランドルールは、空気を和ませるだけでなく、**本番の型を前もって体で覚えてもらう**ためにも使う。ただし、型は説明しても身につかない。ルールを読み上げ、手順どおり練習させるだけだと、人はなじまず、形だけ守るか、白けて離れる。

人がなじむのは、次の順で型に出会うとき。

1. **人がやってみせる**のを見る（進行役が自分の話で、型どおりに話す）
2. **軽い題材で、自分もやってみる**（正解がなく、誰でも話せる題材）
3. **やってみて気づいたことを、自分の言葉で言う**（「物の話より、その物で何ができるかを話すほうが、その人が見えた」）
4. 本番の前に、**その気づきを進行役が一言で拾って**つなぐ

型の名前は、こちらが先に付けるより、参加者が気づいた言葉を使うほうが残る。

## 人がなじむための原則

設計のたびに、この7つに照らす。根拠は末尾の「根拠」にまとめた。

1. **本番とつながっている**：アイスブレイクは時間つぶしではなく、本番の予告。終わりに「今のと同じことを、このあとやります」と言える作りにする。本番とつながらない遊びは、大人には時間の無駄に見えやすい。
2. **先に人がやってみせる**：説明より見本。進行役（またはスタッフ）が、自分の小さな実話で型どおりに話す。わざと一度ふだんの型（「便利だから」）で言ってから、「…いや、本当は、母が一人で出かけられるからだな」と言い直してみせると、型の違いが一度で伝わり、場も笑う。
3. **体と五感から入る**：手癖は頭ではなく体に入っている。だから型も体から入れる。昨日の一場面を、見えたもの・聞こえた音・におい・手ざわりで思い出してもらうと、一般論ではなく場面で話しやすくなる。立つ、歩く、物を手に取る、も同じ。
4. **自分で気づいて、自分の言葉にする**：やったあとに「何に気づいた？」と聞き、出てきた言葉で型を言い直す。こちらの用語（「一段上の理由」）を押しつけない。
5. **許可は、最初から何度も、人が直接言う**：「話さなくてもいい」「いつでもお茶を飲みに立っていい」「形の話をしたくなったら、この紙に書いていい」。こうした許可は、一度言っただけ、紙に書いただけでは使われない。最初に言い、途中でも言い、近くの人が直接「どうぞ」と誘って、初めて使われる。
6. **支えは最初は厚く、慣れたら減らす**：初めは見本・欄・追い問いではっきり支える。慣れが見えたら、言わなくてもできるように少しずつ外す。一度の場で全部外そうとしない。回をまたぐ場では、前の回の様子を見て次の回の支えの厚さを決める。
7. **外れても、拾ってから戻す**：型の外の話（形の提案、前提への違和感、要望）は消さない。置き場（紙、欄、受け皿の人）を用意し、「これも届けます」と受け取ってから、型に戻す。外れた人を直そうとすると、場が固くなる。

## 手順

🧭 AI設定ページの自分ルール（このスキルの欄）があれば先に読む。手持ちのアイスブレイク集の置き場（論理名 `icebreak_library`）が書いてあれば、手順5で使う。

### 0. 受け取る

分からないものだけ、まとめて1回聞く。

- 本番の中心の問い（問いの言葉そのもの）
- 答えを誰が何に使うか（例：行政が計画の「めざす姿」を書く材料にする）
- 参加者（人数、年代、慣れ、温度）と、場にいる立場の違う人（行政の職員、専門家、主催者）
- 本番までの流れと時間、会場、使う道具（カード、シート、スライド、お茶など）

### 1. 求める型を、答えの例で書く

型を抽象的に書かず、**実際の材料で答えの例を2列に並べる**。

| ふだんの型で出る答え | この場で欲しい答え |
|---|---|
| 「医療は人命に関わるから大事」（一般論） | 「夜に子どもが熱を出したとき、車で10分の病院が開いていて助かった」（自分の場面） |
| 「バスの便を増やしてほしい」（形・要望） | 「バスがあると、運転しない母が自分で買い物に行ける」（形の一段上の理由） |

右の列から、型を**動き**で一文にする。例：「形 → それがあると何ができるか → それを感じた場面」。この一文が、以降の仕掛けすべての軸になる。参加者に見せるときは、この一文ではなく右の列の例そのものを見せる。

### 2. ずれを予想する

1の左の列がなぜ出るかを、構造から見る。人のせいにしない。

| 手癖 | 生みやすい構造 |
|---|---|
| 形・施策の提案に流れる | 道具の文面がサービスの形で書いてある／事前情報に「ほかの例」がある／形を決める側（行政の職員）が近くにいる |
| 一般論・正論で答える | 「なぜ」と聞く／自分の場面を聞く追い問いがない |
| 要望・不満になる | 場の目的と範囲（この場で何を話し、何は別の場で扱うか）が示されていない |
| 前提に引っかかって入れない | 前提（例：人口が減る）への気持ちを受け止める場面がない |
| 問いを忘れて周辺の話になる | 説明から本番まで時間が空いて、直前の念押しがない |
| 緊張して話せない・話さない | 許可がはっきり言われていない／いきなり全体の前で話す／居場所（お茶など）がない |

### 3. 支えの厚さを決める

次の3つを見て、支えをどれくらい厚くするか決める。

- **硬さ**：この場がどれくらいはっきりした型を求めるか（ブレストのように硬いか、雑談に近いか）
- **ずれ**：その型が、参加者のふだんの話し方とどれくらい違うか（手順1の2列の差）
- **回数**：1回きりか、回をまたぐか。回をまたぐなら、後の回ほど支えを減らせる

型を支える担い手は、言葉（ルール・念押し）・物（シートの欄、カード、お茶）・人（進行役、巡回する人）の3つ。言葉だけに頼らず、物と人に分けて持たせる。逆向きに引っぱる担い手がいないかも見る（例：形を決める側の人が、形の質問に答えてしまう）。

### 4. 仕掛けを層で組む

1つの仕掛けに頼らない。次の層から、場に合うものを選んで重ねる。

| 層 | 何をするか | 人がなじむための工夫 |
|---|---|---|
| 居場所 | お茶コーナー、立って話せる場所など、型の外で息をつける場所 | 置くだけでは使われない。最初から何度も「いつでもどうぞ」と言い、スタッフが直接誘う（原則5） |
| 見本 | 進行役が、自分の小さな実話で型どおりに話してみせる | ふだんの型で一度言い、言い直してみせる（原則2）。短く、少し笑える話にする |
| アイスブレイク | 本番と**同じ型**を、**軽い題材**で一度やる（手順5） | 体と五感から入る（原則3）。終わりに気づきを聞く（原則4） |
| グランドルール | 型をルールの言葉にする | 4つまで。禁止より「こうする」で書く。参加者の気づきの言葉を使えるなら使う。話さない自由（パス）も入れる |
| 必ず聞く追い問い | 話し手が話し終えたら、聞き手が決まった問いを**必ず**投げる。すでに答えていても投げる | 問いは1〜2個にしぼり、言い方は柔らかく（「それがあると、何ができるんですか？」）。任意のヒントは使われないと考える。問いの言葉は question-design で作る |
| 道具の欄 | シートの欄を型の順に並べる（形 → 何ができるか → 場面） | 書く欄がそのまま型になる。説明を読まなくても使える作りに |
| 直前の念押し | 本番の直前に、見本の話やアイスブレイクで出た気づきをもう一度言う | ルールの読み上げではなく、さっき場で出た言葉を拾う |
| スタッフの声かけ | 巡回する人に、型に戻す一言を前もって渡す | 前もってスタッフにも見本を見せ、一度やってもらう。形を決める側の人は、形の質問に答えず、一段上を聞く役にする |
| 受け皿 | 型の外の話を置く紙や欄を用意する | 「これも届けます」と受け取ってから戻す（原則7） |
| 範囲の示し方 | 冒頭で、全体の中でこの場が受け持つところと、受け持たないところを示す | 範囲が見えないと、範囲の外の話に流れる |

### 5. アイスブレイクを作る・選ぶ

手持ちの集（`icebreak_library`）や一般のアイスブレイクから探すときは、**題材ではなく型が同じか**で見る。作り変え方：

1. 本番の型の一文（手順1）を、そのまま流れにする（例：「身近な物を1つ挙げる → それがあると何ができる？ → それを感じた最近の場面は？」）
2. 入口を体と五感にする（例：かばんやポケットから物を1つ出して手に持つ／昨日の一場面を、音やにおいまで思い出す）
3. 題材を、答えに正解がなく、誰でも話せる軽いものにする。本番の題材（例：当たり前カード）は使わない。本番の答えを先取りしてしまうため
4. 本番と同じ人数・同じ役（話す、聞く、追い問いを投げる）でやる
5. 進行役が最初に一度やってみせる（原則2）
6. 終わりに「やってみて、何に気づきました？」と2〜3人に聞き、その言葉で型を言い直して、「今のと同じことを、このあとカードでやります」とつなぐ

一般のアイスブレイク（体を動かす、手あげ、拍手のリズム遊び）は、型の練習とは別の役目（声と体を出す、正解がない空気を作る、笑う）として使ってよい。どちらの役目かを分けて置く。

### 6. 答えの例で試す

勧める前に、作ったアイスブレイクと追い問いを、参加者になったつもりで立場の違う3〜4人分演じて書く。question-design の「勧める前に、答えの例で試す」と同じやり方で、次を確かめる。

- アイスブレイクの答えが、手順1の右の列と同じ動きになっているか
- 1回やって型が見えるか（ステップが多すぎないか）
- 恥ずかしい思いをする人、話したくないことを話させられる人がいないか
- 立場の上下（行政の職員と市民など）がある場で、どちらかが気まずくならないか
- 時間に収まるか（アイスブレイクは5〜10分が目安）

### 7. 出し方

最初に、求める型の一文（手順1）を書く。次に表で示す。

| いつ | 仕掛け | 何の型を体で覚えるか | 進行役・スタッフの一言 | 分 |
|---|---|---|---|---|

最後に、これがあっても外れたときの受け皿を一行書く。長さは question-design の「出し方」に合わせ、スマホの1〜2画面を目安にする。

## 避けること

- ルールを読み上げるだけで、見本を見せない
- 本番とつながらない「楽しいだけ」のアイスブレイク
- 全員の前で一人ずつ話させる（最初は2〜3人で）
- 自分の弱みや家庭のことなど、話したくない話を引き出す題材
- 追い問いを3つ以上にする（覚えきれず、詰問に聞こえる）
- 許可（話さない自由、お茶、受け皿）を一度だけ言って終わる
- 外れた人を、その場で正す

## ほかのスキルとの分担

- 問いの言葉そのもの（中心の問い、追い問い）は **question-design** で作る。このスキルは、その問いに答える型を本番前に身につけてもらう仕掛けを作る
- 説明スライドの流れ（範囲の示し方、前提への気持ちの受け止め）は **slide-design** と合わせる
- 選んだ・捨てた案の記録は、question-design の「終わりに記録する」に従う

## ふりかえりで使うとき

場のあとに「理由まで深まらなかった」「要望ばかりだった」などが出たら、手順1と2を逆向きに使う。出た答えを左の列に並べ、どの構造が生んだかを見る。うまくいった仕掛け（例：お茶コーナー、手あげ）も、何がそれを働かせたか（誰が、いつ、何と言ったか）まで書き残す。次の回の支えの厚さを手順3から組み直す。

## 根拠

確かさ：A＝一次資料・査読論文・開発元の公式資料／B＝専門家の著作・公的機関の実践資料／C＝報道・実践者の記事。

| 原則 | 根拠 | 確かさ |
|---|---|---|
| 1 本番とつながる | Liberating Structures：どの場の進め方も「問いかけ・空間と物・参加の配り方・組み方・順番と時間」の5要素でできていて、ふだんの会議ではそれが暗黙になっている（Lipmanowicz & McCandless）。Impromptu Networking は場の目的につながる問いで始める | A |
| 1 本番とつながる | アイスブレイクが嫌われるのは、目的とつながらない、うまく作られていないものの経験から（Chlup & Collins 2010 ほか） | B |
| 2 見本 | 構成的グループエンカウンター：インストラクション（リーダーの手本）→エクササイズ→シェアリング（國分康孝ら） | B |
| 2・6 見本と減らし方 | 認知的徒弟制：見本を見せる→手を添える→支えを減らす→見守る。考えている中身を見えるようにする（Collins, Brown & Newman 1989） | A |
| 6 減らし方 | 例題の手順を少しずつ抜く「フェーディング」は初心者に効くが、慣れた人には支えが多すぎると逆効果（認知負荷理論、Renkl ほか） | A |
| 3 体と五感 | 被抑圧者の演劇：くり返しの手癖は体に入っており、体と五感の遊びで「機械的なくせ」をほどく。昨日の一場面を五感で思い出す練習がある（Boal『Games for Actors and Non-Actors』）。手癖と社会の型をつなげた研究（Bourdieu のハビトゥスとの比較） | B |
| 4 気づきを言葉に | ORID：事実→感じたこと→意味→次の行動の順で問うと、表面から深いところへ進む（ICA, Stanfield） | B |
| 形→理由の動き | ラダリング：物の特徴→それで何が起きるか→その人の価値、と問いを重ねる面接法（Reynolds & Gutman 1988）。ただし面接者に熟練が要るとされるので、追い問いは少なく簡単にする | A |
| 5 許可 | 心理的安全性：参加の「ハードル」を下げ、問いかけと仕組みで参加を招く（Edmondson） | A |
| 5 許可 | サークルの対話：話す・黙って持つ・パスする、を選べることが怖さを減らす | C |
| 居場所 | ワールド・カフェ：待ち時間のコーヒーから生まれ、もてなしの空間（飲み物、小さな机）を原則に置く | B |
| 避けること | アイスブレイクは参加者に恥をかかせたり、参加を強いたり、立場の上下を無視したりしないこと | C |
| 現場の気づき | お茶コーナーは、最初から何度も「いつでもどうぞ」と言い、直接声をかけて初めて使われ、場をやわらかくした（市民ワークショップでの進行役の実践知） | 実践知 |

まだ確かめていないこと：WS固有の型を練習させるアイスブレイクと、一般的なアイスブレイクとで、本番の話の深さがどれくらい違うかを比べた研究は見つからなかった。原則は、近い分野の知見と実践知を組み合わせたもの。
