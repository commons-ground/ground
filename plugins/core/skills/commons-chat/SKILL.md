# コモンズの話し合いの場

コモンズの参加者どうしは、Discord などの話し合いの場で気軽にやり取りする。各自の Claude は、コモンズのコネクタの `discord_channels`・`discord_read`・`discord_post` で、そこを読んだり書いたりできる。道具が無いときは、はじめかたの「話し合いの場と入口をつなぐ」がまだなので、その手順を案内する。

話し合いの場は**情報を回す場所**で、残す場所ではない。決まったこと・残す知識は、harvest でスキルや知識コモンズに移す。

## 読む

| 頼まれたこと | すること |
| --- | --- |
| 「Discordで何話してた？」 | `discord_channels` で一覧 → 動きのあるチャンネルを `discord_read` で読み、話題ごとに3〜5行でまとめる。誰が何を言ったかは名前だけ添える |
| 「決まったことは？」 | `pinned_only` で 📌 の付いた発言だけ読む |
| 「この前の通話で何決めた？」 | `#議事録` を読む（通話の議事録と文字起こしのファイルが置いてある） |
| 返事をしたい | 読んだ発言の `id` を覚えておき、書くときに `reply_to` に渡す |

## 書く

- 書く前に、書く文面を利用者に見せる（`discord_post` は毎回許可を聞かれる）
- 書き込みはボットの名前で出て、末尾に頼んだ人の名前が付く。「〇〇さんの Claude より」などは書き足さない
- 短く書く。長い資料は Notion や GitHub に置いてリンクを貼る
- **事業データを書かない**（人名・金額・取引先・住所・口座・自社の Notion や Drive の URL）。ここは複数の事業者が集まる場所
- 人を呼び出す（@ユーザー名、@everyone）ことはできない。急ぐ話は本人に直接伝えてもらう
- 口調は Discord らしく、ゆるく・ちょっとおちゃらけて。むずかしい漢字や仕組みの名前（篩・受付・差し戻し など）は避け、ひらがなや絵文字でくだく（例：「🧺 ふるいにかけたよ〜！」）。ボットや仕組みが自動で返す文面も同じ口調にする

### どのチャンネルに書くか

| 中身 | チャンネル |
| --- | --- |
| 「こんなの作った」「こんな使い方してる」 | `#一般` |
| 提案（スキル・仕組みをこう直したい） | `#提案`。書いたものはすべて提案として篩にかかる |
| スキル・仕組みについての相談、試行の報告 | `#スキルの相談` |
| コモンズのAI（`/ai`）への質問 | `#aiに聞く`（これは Discord の画面から人が打つ） |

チャンネル名はコモンズごとに違うことがある。`discord_channels` の一覧と説明に合わせる。

## 作ったものを知らせる

スキル・アプリ・知識をコモンズに入れたら（propose-change でプルリクエストを出したら）、`#一般` に2〜3行で知らせる。

```
〔できた〕（何ができるか、1行）
使い方：（Claude に何と言えばよいか）
（プルリクエストかページのリンク）
```

利用者が「知らせなくていい」と言ったら書かない。

## GitHub につないでいない人の提案

`#提案` に書いてもらう（形は propose-change の4に近いほどよいが、短くてもよい）。ほかのチャンネルからは `/propose`、ほかの人の発言は「コモンズに提案」で `#提案` に載る。`/propose` と「コモンズに提案」は篩の係（core の sieve）が自動で受け付け、篩のカードのリンクを出した本人に返す。`#提案` に直接書いたものは、harvest で拾われて篩に入る。

## Discord の画面から AI を使う（人に案内するとき）

| したいこと | Discord で |
| --- | --- |
| AI に聞く | 会話の中なら `@コモンズのAI 質問`（読んだら 👀、1〜2分で返信。リプライで続けられる）。単発・急ぎなら `/ai 質問`（すぐ「考え中…」が出る） |
| 入ったものを戻す | `#提案` に「〇〇（プルリクエストの番号か試行の名前）を取り下げて」。篩がすぐ戻すプルリクエストを出す（確認は要らない） |
| 提案を出す | `#提案` に書く。ほかのチャンネルからは `/propose 内容`、ほかの人の発言は「…」→「アプリ」→「コモンズに提案」で `#提案` に載る |
| 通話を議事録にする | 通話の中で `/record start`。全員が抜けるか `/record stop` で止まり、議事録が `#議事録` に、改善の候補が `#提案` に自動で出る（篩が拾う） |
| 一覧を見る | `/help` |
