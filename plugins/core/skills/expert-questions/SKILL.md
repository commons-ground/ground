# 外の人への質問の作り方

**調べれば分かることは聞かない。残った本物の不確かさだけを、相手が即答できる形で聞く。** 良い質問は「宿題を済ませた人の確認」で、「丸投げの問い合わせ」ではない。

外の人の時間は、身内の確認よりさらに高くつく。往復が増えるほど答えが遅れ、関係にも響く。

## 1. 手順

0. **相手を決める。** 相手で言葉も粒度も、そもそも聞くべきかも変わる。現場の人に聞くことを専門家に送らない。自分たちの道具の作りの話（どの列を必須にするか、など）は外に聞かない
1. **聞く前に、自分たちの記録を引く。** 引く順番は：①自分たちの決定の記録・確認済みの事項 → ②過去の質問と回答（議事録、回答待ちの質問の一覧） → ③現場と道具の実際 → ④法令・公式の資料（最後）。答えがもうあるなら聞かず、記録に反映する
2. **本物の不確かさだけを切り出す。** 当たり前のこと・一般常識・自分たちの道具の都合は削る。「この状況に、どの規則が、どう当てはまるか」が決まっていない一点だけを残す
3. **1問1論点にする。** 別の概念を1問に混ぜない（例：量を測ることと成分を測ること、記帳と税額の計算）。論点が2つなら2問に分ける
4. **重なりを消す。** 同じ相手の既存の質問と突き合わせる。同じ論点が言葉を変えて既にあることが多い。語の一致で探さず、読んで判断する
5. **確認の形にする。**「〜は必要ですか？」でなく、調べた理解を述べて「〜という理解で正しいですか？」と聞く。相手が「はい」か「いいえ、〇〇です」で即答できる
6. **具体例を必ず1つ。** 数字と場面で（「300L のタンクから 120L を移したとき…」）。抽象論の往復を防ぐ
7. **相手の言葉だけで書く。** 社内の略語・符丁・英語の略語・内部の番号を入れない。相手の分野の専門用語はよい
8. **それだけで読めるようにする。** 前提と背景を1文入れる。ほかの質問や社内の事情を知らないと読めない文にしない

## 2. 出す前の1行（書けなければ、その質問は出さない）

> この質問を送る理由：〈引いた記録の場所〉に答えが無く、〈回答待ちの質問〉とも重ならない

「調べたか」でなく「**どこを引いたか**」を名指しする。チェックボックスは自己申告で通るが、記録の場所は引いていなければ書けない。

- 法令を全階層読んで条文を引用した質問は、調べて見える。でも答えは自分たちの記録にあった、ということがよくある。だから引く順は記録が先、法令が最後
- 引かなかった窓は「④は開いていない。①で答えが出たため」と書く。読まなかったことを黙らない
- 重ならないと言うときは、根拠の一文を引く。引けないなら「重なりは確かめきれていない」と書く

## 3. 結論はどちらか1つ

- **聞かない**：答えのある場所＋その一文＋次の一手
- **聞く**：上の1行＋相手＋そのまま送れる質問文

曖昧に両方は返さない。送るのは人（送る操作は when-to-ask の「戻せない」に当たる）。

## 4. この作法が見ないもの

- 「同じ論点か」は解釈なので、語が違っても同じ・語が同じでも別、のどちらも起きる
- 専門家の答えの正しさは見ない。返ってきた答えは、出どころと日付を付けて記録に残す
